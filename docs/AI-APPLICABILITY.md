# AI applicability

SharkTank contains deterministic computer-controlled sharks. Their movement and decisions are rule-based code driven by a seeded pseudorandom generator. The same seed and ordered actions reproduce the same state. There is no trained model, inference service, adaptive learning, prompt input, foundation model, biometric processing, or automated decision about a person.

The project nevertheless maintains an ISO/IEC 42001 readiness register because the agents are presented as an AI-system case study. The register records exclusions and limitations instead of implying that controls designed for trained or externally supplied models are active here.

The relevant impacts are game fairness, transparency that opponents are computer-controlled, deterministic replay, resource consumption, and avoiding claims that readiness is certification. A future learned or externally hosted model would change the system boundary and require a new impact assessment, supplier review, data-governance analysis, monitoring plan, and policy update before deployment.
