# v1.2.0

Consolidates SharkTank's public production-governance experience into four canonical destinations: Overview, Controls, Evidence, and Play. The controls surface preserves the complete ISO/IEC 27001 and ISO/IEC 42001 register and policy set; the evidence dashboard preserves live availability, incident, continuity, receipt, spend, degradation, logging, and change records.

Accessibility is treated as a production requirement. The server-rendered governance pages, menu, settings, and supported game controls target WCAG 2.0 AA with keyboard operation, visible and managed focus, semantic status output, contrast and text-scale options, and reduced-motion support. This scope does not claim that every spatial visual interaction has a fully equivalent nonvisual experience.

Legacy human routes redirect directly to the relevant canonical section. Machine evidence, APIs, protected administration, Durable Object names, storage bindings, and migration contracts remain unchanged.

Production deployment remains governed by the protected semantic-tag release workflow.

Tag target: ST-035.
