# v1.1.0

Reframes SharkTank as a technical governance case study. The governance overview is now the public front door, with dedicated ISO/IEC 27001 and ISO/IEC 42001 implementation pages, a live evidence index, and a simplified primary navigation that keeps the game at `/play/` as the governed workload.

Existing control, policy, operations, logging, cost, API, compatibility, and protected administration routes remain available. The release changes no storage schema, binding, or durable-state contract.

Production deployment remains governed by the protected tag-driven release workflow.
